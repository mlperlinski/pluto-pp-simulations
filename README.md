# PLUTO Monte Carlo Simulations of p+p Collisions

## 1. About the Project
This project contains Monte Carlo simulations of proton-proton ($p+p$) collisions at a kinetic beam energy of 1.2 GeV on a stationary target. Developed using the ROOT framework and the PLUTO package, it models the production and decay of unstable particles, specifically $\Delta$ resonances and $\pi^0$ mesons. The code serves as a practical demonstration of various PLUTO programming techniques, ranging from Descriptor Strings and manual decay channel construction to using the `PDecayManager` for handling multiple reaction channels with specific branching ratios.

## 2. Repository Contents
* **Simulation Macros:** `macro1.c`, `macro2.c`, and `macro3.c` simulate the $p+p \rightarrow p+\Delta^+$ reaction using different techniques, including Descriptor Strings, `PParticle` and `PChannel` objects, and a decay manager for multiple channels.
* **Mass Reconstruction:** `macro4.c` reads the generated ROOT tree and reconstructs the $\pi^0$ invariant mass from two photons.
* **Kinematic Filtering:** `macro5.c` introduces an angular acceptance filter for charged particles, requiring emission angles in the laboratory frame to be within $20^\circ \leq \theta \leq 70^\circ$.
* **Data Analysis:** `macro6.c` analyzes the filtered output from `macro5.c` and plots the angular distributions of the proton and $\pi^+$ to verify the filter's functionality.

## 3. Running Instructions

### Step 1: Load the PLUTO library
First, launch ROOT and load the PLUTO library by executing: 
```cpp
gSystem->Load("$PLUTOLIBDIR/libPluto.so");
```

### Step 2: Run the ROOT macros
Run the individual macros in ROOT: 
```cpp
.x macro1.C
.x macro2.C
.x macro3.C
.x macro4.C
.x macro5.C
.x macro6.C
```
*Ensure you execute them in the correct numerical order, as the analysis macros require the ROOT output files generated by the earlier simulation steps.*

## 4. Physical Conclusions
* **$\pi^0$ Mass Reconstruction:** Under ideal Monte Carlo conditions without detector resolution effects, combining the momenta of two emitted photons yields a sharply peaked delta-like distribution. This peak sits accurately at approximately 0.135 GeV/c², matching the expected $\pi^0$ invariant mass.
* **Kinematic Filtering:** Applying the $20^\circ$ to $70^\circ$ angular acceptance filter rejects the vast majority of the 100,000 generated events. This massive drop in accepted events indicates that the reaction products at a 1.2 GeV beam energy are strongly forward-directed.
